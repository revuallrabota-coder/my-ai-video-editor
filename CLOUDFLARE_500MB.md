# Несколько видео в один Reels: до 500 МБ с iPad

**Режим:** от 1 до 12 исходных роликов, **500 000 000 байт суммарно**, общая длительность до 125 секунд. Получается один готовый MP4 с сохранённой речью, субтитрами, эффектами и анимированными вставками.

**Состояние:** исходный код в GitHub обновлён. Для начала реальной загрузки нужно вручную развернуть новую версию существующего Cloudflare Worker, иначе опубликованный Worker продолжит ограничивать старой цифрой. Даже успешные тесты GitHub не заменяют реальную загрузку 400–500 МБ.

## Как пользоваться с iPad

1. Открой [мини-приложение AI Монтажёр](https://revuallrabota-coder.github.io/my-ai-video-editor/) **из меню Telegram-бота**, иначе Telegram не выдаст данные безопасной авторизации.
2. Нажми **«Выбрать несколько видео»** или **«Добавить ещё видео к проекту»**. Допускается максимум 12 файлов MP4, MOV, M4V, WEBM или MKV, объём всех файлов вместе не больше 500 МБ.
3. Отредактируй порядок при помощи **↑ / ↓** рядом с именем каждого клипа. Удалить ошибочно добавленный ролик можно кнопкой **×**.
4. Выбери **«Мой стиль»** и понравившиеся субтитры, камеру, графику, звуки. В качестве примера можно взять съёмку с нескольких ракурсов.
5. На последнем шаге вставь HTTPS-адрес своего Cloudflare Worker без /health и нажми **«Смонтировать Reels»**. Приложение отправит каждый файл частями по 4 МБ, отображая суммарный прогресс.
6. При обрыве соединения выбери на том же устройстве **те же файлы в том же порядке** и с теми же настройками, нажми «Смонтировать Reels» ещё раз. Переданные части сохраняются 3 часа; приложение умеет продолжить их загрузку.
7. GitHub Actions скачает клипы, приведёт разное разрешение, частоту кадров и аудио к одному формату, склеит их в выбранном порядке, распознает **общую речь** и пришлёт текст на проверку в Telegram. Ответь /ok, /fix ошибка=правильно или /text НОВЫЙ ТЕКСТ.
8. Монтаж применит титры и вставки ко всему собранному ролику. Готовый MP4 до ~48 МБ бот отправит как документ. Более крупный результат до 250 МБ скачивается в мини-приложении кнопкой «Скачать готовое Full HD».

**Зачем ограничение 125 секунд:** текущий редактор настроен на Reels до двух минут. Если исходники суммарно длиннее, редактор откажется их обрезать случайным образом и сообщит об этом. Сначала выдели подходящие фрагменты.

## Новое: смысловой монтаж и твои ZIP-наборы

На странице настройки субтитров теперь включён режим **🎯 Смысловой монтаж**. Он работает по распознанной речи, а не размещает заставки через равные интервалы:

- **«Найди ошибку»**, «рассмотри деталь» → лупа или небольшой крестик, если слова действительно относятся к проблеме.
- **«Исправили», «результат»** → галочка на смысловом акценте.
- **«Три секунды», «сколько времени»** → анимированные часы.
- **«Сравним два варианта»** → большой коллаж из кадров исходного ролика.
- **«Съёмка», «монтаж видео» в конкретном контексте** → отдельная графическая сцена.
- **Общее рассуждение о маникюре без визуально важного события** → никаких крупных наклеек. Останутся субтитры и деликатное движение камеры.

По умолчанию включён **редкий смысловой режим**. Бот выбирает только подходящие моменты с большими паузами между эффектами. После подтверждения распознанного текста он сообщает **план, какие смысловые вставки применит**, либо что они не нужны.

Пользовательские ZIP-файлы передаются **приватно, вместе с конкретным монтажным проектом**:

1. На странице настроек выбери **«Твои наборы анимированных вставок»**.
2. Выбери до **четырёх ZIP-пакетов**; все архивы вместе должны занимать **не более 100 МБ**. Эти 100 МБ считаются отдельно от лимита 500 МБ на исходные видео.
3. Подойдут приложенные архивы **Free-Animated-Icon-Sets**, **PB-Free-Camera-Shake-Presets**, **PB-Motion-Graphics-for-Premiere** и **PB_TrailerConstructionSFXLite**. Но совместимы с FFmpeg напрямую только готовые видеоклипы MOV из первого архива и WAV из четвёртого.
4. Из второго архива `.ffx` и третьего `.mogrt` извлекаются **только смысловые рекомендации**, оригинальные Adobe-шаблоны не запускаются в нашем FFmpeg-редакторе. Для соответствующей идеи применяются собственные анимации и переходы бота.
5. Анимированные MOV (крестик, лупа, часы, галочка, стрелка и др.) появляются только при подходящем фрагменте речи. Архивы не попадают в GitHub.
6. Переключатель **«Добавлять редкие тихие звуки из ZIP»** изначально выключен. Если включить, короткие звуки WAV будут очень тихими и только при действительно подходящих эмоциональных акцентах. Голос не заменяется.

**Лицензии:** в PDF-инструкциях PremiumBeat прямо запрещено передавать или распространять исходные пресеты/шаблоны как отдельные файлы. Поэтому мы не размещаем оригинальные `.mov`, `.mogrt`, `.ffx` и `.wav` в публичном репозитории. Частный, временный ZIP загружается исключительно для создания твоего конкретного видео.

**Внимание:** архивы, прикреплённые к чату ChatGPT, не переходят автоматически в Cloudflare Worker. Для монтажа с ними выбери ZIP в разделе «Файлы» на iPad. Без архивов смысловой монтаж всё равно работает на собственных встроенных графических сценах.

## Один раз включить новый Worker

1. В Safari открой [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → существующий Worker (ранее использовался **black-violet-9e64**).
2. Проверь Settings → Bindings: KV namespace с именем переменной **UPLOADS**. Секреты TELEGRAM_BOT_TOKEN, OWNER_TELEGRAM_ID и GITHUB_PAT остаются в Secret, не копируй их в сам код.
3. Открой GitHub-файл [cloudflare_launcher.js](https://github.com/revuallrabota-coder/my-ai-video-editor/blob/main/cloudflare_launcher.js), нажми **Raw**, скопируй весь код.
4. В Cloudflare открой **Edit code**, замени старый Worker JS и нажми **Deploy**.
5. Открой \`https://ТВОЙ-WORKER.workers.dev/health\`. Проверяй \`"max_upload_mb":500\`, \`"max_files":12\` и \`"uploads_500mb_configured":true\`. До появления этих полей реальный Worker не обновился.
6. GitHub Pages Mini App обновляется автоматически из ветки main, но Worker Cloudflare так не обновляется.

## Техническая архитектура и лимиты

- На входе Cloudflare Workers KV хранит **до 500 МБ всего проекта**, в отдельных ключах по **4 МБ**. Количество частей равно сумме \`ceil(размер_клипа / 4_000_000)\` для каждого файла (при 500 МБ и 12 клипах максимум около 136). Каждая часть в KV проверяется по метаданным, без объединения 500 МБ в память Worker.
- На GitHub Actions файлы скачиваются на диск отдельно, затем последовательно нормализуются к 1080×1920/30fps (или 720×1280/30fps в balanced), AAC аудио 48kHz; для беззвучных фрагментов добавляется тихая дорожка. Сначала **склейка**, потом распознавание, монтаж и субтитры.
- По состоянию на ноябрь 2026 года бесплатный Workers KV ограничен 1 ГБ хранилища, 1000 записей в день, 25 МиБ на одно значение. Проект 500 МБ вместе с конечным MP4 размером 250 МБ занимает около 750 МБ. Запускай по одному крупному проекту и скачивай результат своевременно. Исходники удаляются по завершении или спустя три часа.
- Размер конечного MP4 свыше 250 МБ текущий путь через KV не поддерживает без дополнительного хранилища, несмотря на возможность загрузить исходники суммарно до 500 МБ.
- Прямая пересылка видео прямо **сообщениями в чат Telegram** имеет другой путь загрузки и ограничения; крупные проекты нужно отправлять именно через Mini App.
- Файл исходного рабочего процесса GitHub остаётся с историческим именем \`.github/workflows/upload-video-50mb.yml\` ради совместимости со старым Worker URL, но обрабатывает проекты до 500 МБ.
- Проверка разработчиков: [GitHub Actions](https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/check-editor.yml).

## Что это пока НЕ делает

- Не выбирает автоматически лучшие дубли по смыслу. Видео склеиваются **в указанном порядке**, а потом редактор обрабатывает цельную дорожку.
- Не делает из пяти минут материалов короткий ролик сам собой. Суммарная продолжительность исходников должна укладываться в 125 секунд.
- Не гарантирует надёжную обработку тяжелого 500-МБ исходника на бесплатной инфраструктуре без настоящего теста после публикации Worker.

Если нужен каждый из нескольких файлов по 500 МБ, а не **500 МБ суммарно на проект**, понадобится иной объём хранения и отдельная архитектура.
