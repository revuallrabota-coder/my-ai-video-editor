# Обновление: плавающие субтитры и сохранение Full HD

В Mini App появились три новых возможности из загруженного референса:
- subtitle_style=reference_dynamic: разные размеры слов, мягкая анимация,
  красные акценты, мелкие белые подписи и местами полупрозрачные подложки;
- camera_style=cinematic_pan: плавное смещение кадра вправо-влево на
  речевых акцентах с периодическими приближениями без резких скачков;
- export_quality=high: экспорт 1080×1920 / H.264 CRF 18 / AAC 192k.
  Можно выбрать balanced для 720×1280, чтобы снизить нагрузку.

Важное ограничение: на бесплатном Render Full HD обработка может быть
слишком тяжёлой и падать по памяти или времени. Начинай с 10–20 секунд
и при ошибке попробуй balanced. Сервер по-прежнему нужно самостоятельно
развернуть и указать URL на последнем экране Mini App.

# Запуск настоящего монтажа прямо в Telegram Mini App (iPad)

**Статус:** код написан и загружен в GitHub. Это НЕ означает, что сервер уже запущен. Пока Render (или другой HTTPS-сервер) не создан и его URL не введён в Mini App, кнопка «Монтировать видео» не обработает видео.

## Как это работает

GitHub Pages показывает интерфейс, но не выполняет Python/FFmpeg/Whisper. Наш backend editor_api.py работает на внешнем сервере:

1. Открыть Mini App через меню своего Telegram-бота.
2. Выбрать один исходный ролик и настройки.
3. Нажать «Монтировать видео». Видеофайл отправляется сразу на сервер, без ограничений Telegram Bot API на скачивание 20 МБ.
4. Сервер распознаёт речь; приложение показывает исправляемый текст.
5. Нажать «Продолжить монтаж» после проверки.
6. Скачать готовый MP4 через кнопку внутри приложения.
7. Если выбран режим «По референсу», добавить и второе видео.

GitHub Actions больше не нужно запускать для каждого ролика, когда сервер подключён.

## Развёртывание на iPad через Render

**Важно о бесплатном Render:** бесплатный сервер ограничен по памяти/мощности, засыпает при простое и может перезапуститься. Whisper medium слишком тяжёлый для такого первого теста, поэтому для серверной демонстрации выбран Whisper tiny; ошибочные слова можно править вручную. Это прототип, не гарантия стабильного бесплатного профессионального монтажа. Для 1 ГБ и двухминутных видео понадобится более мощная архитектура.

1. На iPad в Safari открой https://dashboard.render.com/.
2. Войди или создай учётную запись Render и подключи свой GitHub.
3. Открой New → Blueprint, выбери репозиторий revuallrabota-coder/my-ai-video-editor (ветка main). Render найдёт файл render.yaml.
4. При настройке защищённых переменных Render укажи TELEGRAM_BOT_TOKEN (токен твоего бота из @BotFather) и OWNER_TELEGRAM_ID (твой числовой Telegram ID). Не помещай их в публичный код и не отправляй в сообщения.
5. Когда сборка будет завершена, скопируй настоящий HTTPS URL созданного сервиса, который Render покажет в панели управления.
6. Добавь /api/health к этому URL и проверь: при работе сервиса должен появиться JSON со status=online.
7. Открой Mini App через меню СВОЕГО Telegram-бота, выбери исходник и настройки, перейди на последнюю страницу, вставь URL Render в поле «Адрес твоего сервера». Нажми «🎬 Монтировать видео».
8. Первый тест: 10–20 секунд, исходник до 20 МБ, режим my_style, камера editorial, субтитры signature. После распознавания исправь слова и нажми «✅ Продолжить монтаж», затем «⬇️ Скачать готовый MP4».

## Безопасность и ограничения

- Мини-приложение нужно открывать ИЗ TELEGRAM. Сервер проверяет настоящую подпись Telegram.WebApp.initData и разрешает работу только владельцу из OWNER_TELEGRAM_ID. Обычная вкладка Safari без Telegram-авторизации получает ошибку.
- Сервер принимает только одно задание одновременно. По умолчанию максимальный размер каждого файла 50 МБ, до 125 секунд; бесплатно разумнее начать с 10–20 секунд.
- Задания/видео хранятся во временной папке и могут исчезнуть при перезапуске или «засыпании» бесплатного сервера. Срок очистки — около двух часов при следующем запросе.
- Шрифты, зум, субтитры, звук, эмодзи и текстовый хук подключены к обработчику, но успешный end-to-end тест на настоящем видео пока не подтверждён.
- Реалистичное AI-переодевание и AI-замена интерьера ещё не реализованы. Вставки фото и загрузка собственных шрифтов также не поддержаны серверным конвейером. Текущий экспорт вертикальный 9:16.
- Перейти на 1 ГБ: прямые загрузки частями в объектное хранилище, отдельный видеоворкер, постоянная очередь, обработка больших файлов. Бесплатный статический хостинг для этого непригоден.

## Ошибки

- 503: проверь TELEGRAM_BOT_TOKEN и OWNER_TELEGRAM_ID в Render.
- 401: открой Mini App из меню Telegram, а не обычной вкладкой браузера.
- 403: твой числовой OWNER_TELEGRAM_ID не совпадает с текущим аккаунтом.
- 409: уже есть незавершённое задание, закончи его.
- 413: видео больше допустимого лимита.
- CORS / сетевой сбой: проверь URL и что CORS_ORIGINS соответствует адресу GitHub Pages.
- Ошибка распознавания или сбой по памяти: открой Logs в Render. На бесплатном сервере обработка может не завершиться, поэтому первый тест делай коротким.

- editor_api.py: проверка авторизации, upload, очередь, транскрибация, render, download.
- Dockerfile, render.yaml, requirements-api.txt: контейнер и установка зависимостей.
- telegram_editor.py, reference_editor.py: FFmpeg монтажный движок.
- font_presets.py, word_captions.py, reels_effects.py: типографика и эффекты.
