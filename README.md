# 🎞 Новое: один анимированный текст на каждое слово + монтажный Zoom

Обновление сделано по просьбе пользователя: прежние подёргивания камеры и субтитры целыми фразами не соответствовали референсу.

## Что выбрать на iPad

Открой [GitHub Actions → Тест монтажа без API ID](https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/test-without-api-id.yml), нажми **Run workflow** и выбери:

| Поле | Новый вариант | Для сравнения |
|---|---|---|
| mode | my_style | auto, reference, captions, cuts |
| subtitle_style | signature = розовое **одно слово** за раз | contrast = красное одно слово; classic = одно слово без курсива; с суффиксом _phrases = старый текст фразами |
| camera_style | editorial = смена общего и крупного плана на границах фраз, с удержанием | soft_punch/enhanced = прежний цикл; gentle/off = лёгкий эффект или без зума |
| audio_profile | balanced | strong/off |
| video_speed | 1.0 | 1.1/1.2 |

Остальные настройки (цвет, положение, шрифт, хук, фильтр) остаются **независимыми**. По умолчанию выставлены новые camera_style=editorial и subtitle_style=signature (теперь это именно **поштучные** слова, а не фразы). Если нужны старые розовые всплывающие фразы, выбери signature_phrases.

## Как это работает

- Речь сначала распознаётся Whisper medium (RU), и бот присылает черновик субтитров. Ответь /ok, /fix ошибка=правильно или /text ПОЛНЫЙ ПРАВИЛЬНЫЙ ТЕКСТ.
- При финальном рендере **каждому слову** создаётся отдельный ASS-титр с fade-in, небольшим увеличением и подъёмом. Соседние события стараются не перекрывать друг друга.
- Камера в редакторском режиме находит начала смысловых фраз, подводит к более крупному плану за ~0,36 секунды, удерживает его, возвращается к общему только на следующем монтажном акценте. Это не постоянное циклическое «дыхание» камеры.
- Розовый/красный/белый, размер, шрифт и положение можно выбирать независимо от анимации.

**Ограничение:** это приближённая монтажная стилистика, а не буквальное покадровое копирование работы стороннего «Чит-Кода». Пока нет продвинутого анализа содержания, B-roll или автоматически воспроизводимых эффектов из любого референса. Реальный Telegram end-to-end тест нового режима ещё не подтверждён; синтетические проверки добавлены в workflow «✅ Проверка кода монтажёра». Ограничение текущей загрузки Bot API — **до 20 МБ** на видео.

# 🛠 Исправление неправильных слов и зума — новая проверка текста

**Почему прежде были ошибки:** предыдущая версия использовала слишком слабую Whisper base, а зум запускала циклом по таймеру. В результате неверная речь попадала в MP4 сразу, а приближения появлялись невпопад.

**Что изменилось:**

- Русская речь распознаётся локальной моделью **Whisper medium** по предварительно очищенной аудиодорожке. Это качественнее, но требует больше CPU-времени; 100% правильность не гарантирована.
- **Обязательная проверка текста перед финальным рендером**: после загрузки исходника бот пришлёт черновик текста. Отправь **/ok**, если всё правильно; **/fix ошибка=правильно**, чтобы заменить отдельные слова (можно несколько через точку с запятой); или **/text здесь полный правильный текст**, чтобы полностью заменить неверную расшифровку. Только после ответа начнётся монтаж. Для режима **cuts** проверка не нужна.
- Если расшифровка не нашла речь, можно указать слова самостоятельно командой /text. Положение слов на таймлайне при крупных исправлениях **приблизительное**, потому что здесь нет полноценного forced alignment.
- Зумы **soft_punch** и **enhanced** теперь планируются по началу фраз и заметным паузам в речи, а не повторяются строго по таймеру. Увеличения имеют плавные края и не должны искусственно дёргать картинку. Исходная тряска камеры при этом не стабилизируется.
- Референс 19679484171381794.mp4 из переписки использовался как визуальный ориентир; точное воспроизведение всех склеек, титров, скриншотов, звуков и ключевых слов не гарантируется.

## Как проверять обновление на iPad

1. Запусти [🧪 Монтаж без API ID](https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/test-without-api-id.yml), настроив режимы на своё усмотрение.
2. Дождись сообщения в Telegram от своего бота и отправь одно исходное видео до **20 МБ** (или два файла, если выбрала режим reference).
3. Когда бот пришлёт **📝 Черновик субтитров**, проверь его.
4. Ответь отдельным сообщением **/ok**, **/fix ошибка=правильно** (для одной или нескольких замен), или **/text Исправленный полный текст речи**. Команда /text должна содержать **весь текст**, а не одно исправленное слово.
5. Бот начнёт финальную сборку. Обрати внимание: распознавание medium на CPU может идти ощутимо дольше, чем прошлый монтаж. После черновика на ответ даётся **15 минут**.

**Статус:** код обновлён; синтетическое выражение FFmpeg для зума было отдельно проверено, но полноценный прогон нового взаимодействия через Telegram и реальный результат ещё не подтверждены.

# 🎥 Новое приближение «Как в Чит-Коде» (без тряски)

По просьбе пользователя режим **camera_style = soft_punch** теперь стоит **по умолчанию** в тестовом Bot API workflow и Mini App.

- Плавное приближение примерно на **11%** за **0,8 секунды**;
- Удержание более крупного плана около **5 секунд**;
- Плавный возврат к общему плану примерно за **1 секунду**;
- Затем стабильный общий план до следующего изменения крупности.
- Без прежнего постоянного «дыхания»/раскачивания камеры.

Это **приближённая интерпретация манеры кадрирования** из пользовательского примера, а не точное копирование движения чужого редактора. Тряску, уже присутствующую в самом исходнике, этот эффект не стабилизирует.

Для запуска через [GitHub Actions](https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/test-without-api-id.yml): **mode = my_style**, **camera_style = soft_punch**, **subtitle_style = signature** (розовый) или **contrast** (красно-белый), **audio_profile = balanced**. Настройку **camera_style = off** можно вернуть, если исходный клип уже очень подвижный.

Синтетический FFmpeg-прогон нового выражения масштабирования завершился успешно; итоговый монтаж в Telegram с реальным исходником после обновления ещё требует проверки.

# 🔎 Два присланных видео: дополнительный сравнительный разбор

Пользователь предоставил два видео одной студийной сцены:
- первый ролик — **61,3 с**, 720×1280/30 fps, **23,8 МБ**; без заметных субтитров;
- второй — **92,9 с**, 720×1280/30 fps, **35,8 МБ**; готовый монтаж с красными акцентными словами, белыми фразами, крупным начальным заголовком, иногда полупрозрачными плашками и водяным знаком стороннего редактора.

На измерении FFmpeg volumedetect средний уровень исходного видео ≈ **-35,7 dB**, а готового ≈ **-18,5 dB** (этот показатель нельзя трактовать как доказательство шумоподавления или сравнение LUFS). Мы сохраняем отдельные режимы очистки голоса и выравнивания громкости.

**Второе видео НЕ устанавливает новую обязательную палитру.** Добавлен выбор:
- **subtitle_style = signature** (по первому референсу): розовый курсив и маленькие белые подписи, мягкое всплытие.
- **subtitle_style = contrast** (по второму примеру): красные крупные акцентные слова + небольшая белая фраза, мягкое всплытие. Чужой логотип не воспроизводится.
- **subtitle_style = classic**: прежние субтитры.

**Стабильная камера:** **camera_style = off** теперь по умолчанию. Цифровые циклические зумы отключены. Если исходник статичен, кадр остаётся статичным; альтернатива **camera_style = gentle** делает один очень небольшой плавный push-in, без постоянного «качания» туда-сюда.

**Ограничение тестового Bot API:** оба присланных файла больше 20 МБ. Для испытания бота потребуется отдельная сжатая копия до 20 МБ и не длиннее двух минут. Не пытайся отправить оригинальные файлы как есть через этот рабочий процесс.

**Статус:** код новых режимов опубликован и добавлены проверки в GitHub Actions. Результат на реальном исходнике после этих изменений пока **не проверен**.

# 🎬 Мой AI Монтажёр

Личное Telegram Mini App и экспериментальный видеомонтажёр на GitHub Actions. Управление с iPad, без платных AI-кредитов за каждый ролик.

- Интерфейс: https://revuallrabota-coder.github.io/my-ai-video-editor/
- Запуск тестового монтажа: https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/test-without-api-id.yml

## ⭐ Монтаж по референсу (новый режим)

**Важно:** новый режим создан в коде, но ещё не проверен полноценным тестовым запуском. Он анализирует пример только по **ритму заметных смен кадров** и делает похожие виртуальные приближения на твоём видео. Это не точное воспроизведение всех переходов, вставок, музыки, анимации и шрифтов из референса.

1. Открой [Actions → 🧪 Тест монтажа без API ID](https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/test-without-api-id.yml).
2. Нажми **Run workflow**, выбери **mode = reference**. Можно оставить цвет субтитров **#E8A0C0**. Затем нажми зелёную **Run workflow**.
3. Открой своего бота в Telegram. **Дождись** сообщения «🎬 Режим „По референсу“ запущен! Шаг 1 из 2…».
4. Пришли **первым** видео-референс (MP4/MOV до **20 МБ**, до 2 минут).
5. Когда бот ответит **«✅ Референс принят!»**, пришли **вторым** свой исходник (тоже до **20 МБ**, до 2 минут).
6. Бот попробует удалить длительные паузы, сделать смену крупности с темпом референса, добавить субтитры и отправить итоговый MP4.

Оба видео отправлять **в чат Telegram**, а не на страницу GitHub. Если бот не прислал сообщение о запуске, пока **не отправляй** файлы. Время ожидания файлов — до 15 минут после запуска скрипта.

### Что перенимается из референса

| Действие | Сейчас |
|---|---|
| Определить примерный ритм склеек по изменению изображения | Реализовано |
| Подстроить смены крупности/зумы под этот темп | Реализовано |
| Удалить длительную тишину в своём видео | Реализовано |
| Сохранить свой голос | Реализовано |
| Автоматические русские субтитры с выделением текущего слова | Реализовано |
| Узнать точный шрифт, место, цвет и анимацию титров в чужом ролике | Не реализовано |
| Повторить B-roll, переходы, маски, графику и звуковые эффекты | Не реализовано |
| Полный AI-перемонтаж кадр в кадр | Не реализовано |

## Другие режимы

В том же workflow доступны:
- **auto**: удалить тишину + субтитры; один исходник;
- **captions**: только субтитры; один исходник;
- **cuts**: только удаление тишины; один исходник;
- **reference**: референс + исходник, два файла.

При открытии Mini App можно выбирать файлы и параметры, **но Mini App пока не передаёт файлы и настройки в GitHub Actions**. Режим и цвет для теста выбираются в GitHub Actions, а видео отправляются в Telegram.

## Почему только 20 МБ

Здесь используется стандартный Telegram Bot API без api_id и api_hash. Метод getFile ограничивает скачивание файлов примерно 20 МБ. **Каждое** из двух видео должно укладываться в 20 МБ. Бот также не может через стандартный Bot API отправить обратно неограниченно большой файл.

Чтобы перейти на исходники **до 1 ГБ**, потребуется прямая загрузка из Mini App на отдельный сервер/хранилище, не через getFile. Кроме того, нужен процессор для обработки большого видео, которому придётся платить ресурсами либо искать ограниченный бесплатный вариант. GitHub Pages монтировать видео не может.

## Что уже настроено

- Публичный интерфейс GitHub Pages.
- Код видеомонтажёра FFmpeg + Faster-Whisper.
- Ручной запуск GitHub Actions.
- Бот работает через обычный Bot API; **не нужен** доступ к my.telegram.org.
- Владелец определяется секретом OWNER_TELEGRAM_ID; чужие видео не обрабатываются.
- Выбранные видео загружаются во временную директорию только на время одной задачи.
- Пользователь сообщал, что предыдущая базовая версия возвращала смонтированный ролик. **Режим по референсу ещё не проверен.**

## Устранение неполадок

- Не приходит «Монтажёр запущен»: проверь, запустился ли шаг «Запустить тестовый монтаж»; возможна ошибка секретов, webhook или конфликт с другим getUpdates-ботом.
- Не принял референс: убедись, что это действительно видеофайл до 20 МБ и до 2 минут.
- Ролик не пришёл: зайди в запущенное GitHub Actions задание и открой логи последнего шага.
- Ролик слишком похож на базовую нарезку: распознавание ритма не равно полному копированию монтажа. Следующий этап — титры и визуальные переходы по анализу референса.
- Не запускай два обработчика этого бота одновременно.
