# Мой AI Монтажёр 🎬

Личное Telegram Mini App для настройки автоматического монтажа роликов.

## Что сейчас работает

- Пять экранов: Видео → Монтаж → Подписи → Эффекты → Итог.
- Выбор нескольких видео и предварительный просмотр первого файла.
- Выбор формата 9:16 / 16:9.
- Выбор режима монтажа, подбор фото и настроек субтитров.
- Цвет текста, шрифты, обводка, тень, положение подписей, хук.
- Настройки камеры, аудио, скорости и фильтра.
- Скачивание выбранных параметров как JSON-файла.

**Пока не работает:** серверная загрузка файлов, удаление пауз, распознавание речи, рендер видео, отправка итогового ролика в Telegram. Этот репозиторий пока содержит только интерфейс (прототип).

## Как опубликовать через GitHub Pages

1. Открой [Settings → Pages](https://github.com/revuallrabota-coder/my-ai-video-editor/settings/pages).
2. В **Build and deployment** выбери **Source: Deploy from a branch**.
3. Выбери **Branch: main**, папку **/(root)** и нажми **Save**.
4. После завершения публикации адрес должен иметь вид:
   https://revuallrabota-coder.github.io/my-ai-video-editor/

Публикация не подтверждена до появления ссылки в настройках Pages.

## Как добавить кнопку в Telegram

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/setmenubutton`.
2. Выбери нужного бота.
3. Вставь **уже опубликованный** HTTPS-адрес мини-приложения.
4. Укажи подпись кнопки: `🎬 Мой монтажёр`.

Не публикуй токен бота в файлах этого репозитория или в чате.

## Следующий этап

Отдельный сервер обработки видео с FFmpeg и распознаванием русской речи (например, Whisper). GitHub Pages не запускает серверные приложения и не монтирует видео. Для роликов до 1 ГБ потребуется отдельное хранилище и вычислительный сервер. Бесплатный публичный хостинг без лимитов не гарантируется.
