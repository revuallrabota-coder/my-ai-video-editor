# 🚀 Самый простой запуск: тест без api_id и api_hash

Если `my.telegram.org` пишет **Too many attempts**, **не нужно создавать новое API-приложение ради первого теста**. Мы добавили независимый сценарий на обычном Telegram Bot API.

**Уже нужны только два секрета**, которые были настроены ранее:

- `TELEGRAM_BOT_TOKEN` — из @BotFather.
- `OWNER_TELEGRAM_ID` — числовой ID твоего Telegram-аккаунта.

Открой [Actions → 🧪 Тест монтажа без API ID](https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/test-without-api-id.yml). Нажми **Run workflow**, оставь режим `auto` и нажми зелёную кнопку запуска. После запуска скрипт пришлёт **в твой Telegram-чат** сообщение «Монтажёр запущен!». Тогда отправь ему **новое** видео MP4 или MOV **до 20 МБ и до 2 минут**.

Движок попробует удалить длинные тихие промежутки, создать анимированные субтитры с выделением слов и вернуть готовое MP4 в чат. Это **прототип; реальная обработка ещё не проверена тестовым заданием**.

**Важные ограничения:** стандартный Bot API скачивает только файлы до 20 МБ. Эта версия **не монтирует 1 ГБ**, не принимает большие файлы из мини-приложения и не работает круглосуточно. Для 1 ГБ потребуется отдельная прямая загрузка файлов на сервер или объектное хранилище; `api_id` для этого не нужен. Telegram отправляет готовое видео через Bot API с отдельным ограничением размера. GitHub Actions здесь запускается **вручную**, а не автоматически по каждому сообщению боту.

# 🎬 Мой AI Монтажёр

Личное мини-приложение Telegram для настройки видеомонтажа. Репозиторий создан для работы с iPad.

## Что уже есть

- [Открыть интерфейс](https://revuallrabota-coder.github.io/my-ai-video-editor/)
- Пять экранов: исходники, монтаж, субтитры, эффекты, итог.
- Предпросмотр первого видео и выбор настроек.
- Отображение своего Telegram ID в итоговом экране (только из Telegram).
- **Отдельный прототип настоящего монтажа**: [GitHub Actions → Монтаж через Telegram](https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/montage.yml).

### Что делает первый движок

- Принимает **одно новое видео** в личном чате бота.
- Проверяет размер (до 1 ГиБ) и длительность (до 2 минут).
- В режиме `auto` удаляет длинные тихие участки аудио и монтирует видео, не заменяя исходный голос.
- Локальная модель Whisper распознаёт речь и создаёт субтитры с выделением текущего слова.
- Конвертирует в вертикальное видео **720×1280** с сохранением исходной композиции.
- Отправляет результат в тот же чат Telegram через MTProto.

Режимы:
- `auto` — убрать тишину + субтитры;
- `captions` — только субтитры;
- `cuts` — удалить тишину без субтитров.

**Пока нет:** автономной работы 24/7, автоматического запуска со страницы Mini App, использования её индивидуальных настроек в рендере, анализа дублей по смыслу, вставок фото, сложных переходов, системы оплаты. Интерфейс пока отдельный от движка. Качество и большие файлы ещё не проверялись на реальном задании.

## ⚠️ Безопасность

Никогда не записывайте в репозиторий, коммиты, issue или README:
- токен бота, выданный @BotFather;
- `api_hash` или другие ключи Telegram;
- приватные видео.

Токены хранить **только как Repository secrets** в GitHub Actions. Видеофайлы скачиваются во временную среду GitHub Actions, а не сохраняются в открытом репозитории. Для особо конфиденциальных видео лучше использовать собственный сервер.

## Настройка через Safari на iPad

### 1. Получи Telegram API ID и API Hash

1. В Safari зайди на [my.telegram.org](https://my.telegram.org).
2. Войди по номеру телефона Telegram.
3. Открой **API development tools**.
4. Если приложение не создавалось, заполни короткую форму. Например:
   - App title: `My Video Editor`
   - Short name: `myvideoeditor`
   - Platform: `Other`.
5. Сохрани отдельно значения `api_id` (число) и `api_hash` (длинная строка). **Никому их не пересылай.**

### 2. Получи токен бота

1. В Telegram открой [@BotFather](https://t.me/BotFather).
2. Команда `/token`, выбери созданного бота.
3. Скопируй токен **в защищённое место**, не в публичный репозиторий.

### 3. Узнай свой Telegram ID

1. Открой собственный Telegram-бот → кнопку **Мой монтажёр**.
2. Выбери небольшое тестовое видео и перейди к **шагу 5 «Итог»**.
3. Там появится строка «Твой Telegram ID» и кнопка копирования.
4. ID — **число**, не @username и не токен.

### 4. Добавь секреты GitHub

Открой [Settings → Secrets and variables → Actions](https://github.com/revuallrabota-coder/my-ai-video-editor/settings/secrets/actions), затем **New repository secret**. Создай четыре секрета по одному:

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен из @BotFather |
| `TELEGRAM_API_ID` | Число api_id с my.telegram.org |
| `TELEGRAM_API_HASH` | Строка api_hash с my.telegram.org |
| `OWNER_TELEGRAM_ID` | Твой числовой ID с последнего экрана приложения |

Ни один из этих секретов не должен быть в `index.html` или другом файле.

### 5. Отправь первое видео и запусти

**Порядок важен: сначала запусти задачу GitHub, а после этого отправляй видео боту.** Бот в этой версии не работает постоянно и не читает старую историю чата.

1. Открой [Actions → Монтаж через Telegram](https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/montage.yml).
2. Нажми **Run workflow**, выбери:
   - `auto` — монтаж + субтитры;
   - цвет `#E8A0C0` или другой шестизначный цвет.
3. Нажми зелёную кнопку **Run workflow**, затем открой новое задание.
4. Дождись, когда шаг **«Ожидать видео и обработать»** начнёт выполняться (а в журнале появится «Бот подключён. Ожидание нового видео»).
5. **Только теперь** открой чат со своим ботом и отправь новое видео MP4 или MOV длительностью до 2 минут и до 1 ГБ.
6. Не запускай второй монтаж одновременно. Через некоторое время бот пришлёт готовый MP4 или сообщение об ошибке.

Если видео не отправлено в течение 15 минут после подключения, задание завершится без монтажа. Для нового видео нужно запускать Actions снова.

### Почему именно так?

GitHub Pages — только статический сайт, он сам видео не монтирует. GitHub Actions позволяет временно запустить процессор в бесплатной среде стандартного раннера публичного репозитория. За ручной запуск не требуется оплачивать AI-генерацию, но доступность среды и лимиты зависят от GitHub.

В обычном Telegram Bot API скачивание файлов ограничено 20 МБ. Используем **Telethon через MTProto**, а не обычный метод `getFile`, для обмена большими файлами. Нужны `api_id` и `api_hash`.

### Важные технические ограничения

- Реальная скорость для 1 ГБ неизвестна, зависит от Telegram и свободного раннера GitHub.
- Обработка может занимать значительно больше длины ролика, особенно распознавание речи на CPU.
- Это **экспериментальный движок**, пока без подтверждённого успешного end-to-end теста.
- Удаление тишины не равно распознаванию неудачных дублей по смыслу.
- Расширенные эффекты Mini App пока лишь интерфейс и не связаны с рендером.
- Некоторые технические лимиты GitHub и Telegram могут меняться.
