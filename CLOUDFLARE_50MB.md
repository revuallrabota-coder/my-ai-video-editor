# Видео до 50 МБ без карты: Cloudflare KV + GitHub Actions

> **Обновлено 21 ноября 2026:** лимит повышен до **300 МБ**. Эта инструкция устарела, актуальные действия: [CLOUDFLARE_300MB.md](CLOUDFLARE_300MB.md). Прямой Telegram Bot API по-прежнему ограничен 20 МБ для скачивания.



**Состояние:** код в GitHub обновлён, но новый Worker ещё не развёрнут в твоём Cloudflare, KV namespace ещё не подключён и полный end-to-end тест на реальном видео не проведён. Старый вариант через Telegram до 20 МБ пока не меняется.

## Что исправлено

- Субтитры больше не забегают вперёд: в режиме «Мой стиль» перестали автоматически вырезать паузы из речи. По умолчанию подписи теперь появляются на +0,30 секунды позже, можно выбрать +0,45, +0,60 или в чате /sync 0.45.
- Маленькие слова объединяются в 2–3-словные мини-фразы, чтобы они не мигали. Крупные смысловые слова остаются анимированными.
- Качество Reels: 1080×1920, 30 fps, H.264 CRF 16. На промежуточных шагах используем CRF 12/14. Это не математически без потерь, но сохраняет детали лучше.
- Исходник до 50 МБ передаётся из Mini App напрямую в приватное облачное Workers KV частями по 4 МБ. Сам монтаж по-прежнему выполняется в GitHub Actions, без Render и без запроса банковской карты.
- Выходной MP4 до ~48 МБ отправляется в Telegram как документ, без дополнительных изменений качества. Если итоговый файл больше, его можно временно сохранить в KV и скачать из Mini App кнопкой «Проверить готовность / скачать Full HD».

## Шаг 1. Создай бесплатное KV-хранилище

На iPad в Safari открой https://dash.cloudflare.com/ . В аккаунте нажми **Storage & databases → KV** (иногда Workers KV расположен в Storage).

Нажми **Create namespace**, назови его **my-video-files** и сохрани. На Cloudflare Workers Free KV входит в бесплатный тариф: максимум 1 ГБ хранения, до 1000 записей в день, до 25 МиБ на одно значение. Если здесь неожиданно требуют карту, сообщи о проблеме, не обходи проверку.

## Шаг 2. Привяжи его к существующему Worker

1. Открой Compute → Workers & Pages → **black-violet-9e64**.
2. Settings → **Bindings** → Add binding.
3. Выбери **KV namespace**.
4. Название переменной / Binding name: **UPLOADS**. Вводи точь-в-точь заглавными буквами.
5. Выбери свой namespace **my-video-files**, затем **Save / Deploy**.

Уже созданные три секрета TELEGRAM_BOT_TOKEN, OWNER_TELEGRAM_ID и GITHUB_PAT сохраняются. Не добавляй и не публикуй их повторно.

## Шаг 3. Обнови код Worker

1. Открой https://github.com/revuallrabota-coder/my-ai-video-editor/blob/main/cloudflare_launcher.js
2. Нажми Raw, скопируй весь обновлённый JavaScript.
3. В Cloudflare Worker black-violet-9e64 нажми Edit code, выдели всё в worker.js (⌘ + A), вставь новый код и нажми Deploy.
4. Открой свой адрес Worker с окончанием /health. Теперь JSON должен показывать статус online и **uploads_50mb_configured: true**. При false проверь привязку UPLOADS.

## Шаг 4. Тест из Telegram Mini App

1. Открой мини-приложение из меню своего Telegram-бота.
2. Выбери видео MP4/MOV 9:16, до **50 000 000 байт**, длительность до 125 сек.
3. Выбери mode my_style, скорость 1.0, subtitle_style reference_dynamic, камеру cinematic_pan, export_quality high (1080×1920). Подстрой задержку титров на +0.30 или +0.45.
4. На последнем экране вставь адрес Cloudflare Worker в поле без /health и нажми **«Загрузить и смонтировать до 50 МБ»**.
5. Держи Mini App открытым во время передачи всех частей, дождись 100%.
6. В чате Telegram-бота придёт черновик распознавания. Подтверди его /ok, исправь через /fix ошибка=правильно или /text ПОЛНЫЙ ТЕКСТ. При необходимости отправь /sync 0.45 перед /ok.
7. Готовый ролик до 48 МБ бот пришлёт как MP4-документ, больший ролик можно скачать через кнопку **«Проверить готовность / скачать Full HD»** на последнем экране Mini App.

## Важные пределы

- Старый запуск через Telegram-чат по-прежнему до 20 МБ: это лимит Telegram Bot API getFile. Новый способ до 50 МБ использует передачу из Mini App, а не getFile.
- Временные загруженные и готовые видео удаляются автоматически примерно через три часа. Скачивай результат сразу.
- 1 ГБ, несколько одновременных пользователей, постоянное облачное хранилище и замена внешности отдельным ИИ пока не реализованы.
- Cloudflare KV имеет ограниченную скорость распространения данных и дневные ограничения бесплатного тарифа. Большие файлы занимают много хранилища, поэтому не запускай много одновременных роликов.
- Видео и исходники доступны только владельцу, который проходит проверку подписи Telegram. GitHub использует токен из закрытого Secret, а не из публичного кода.
- Если GitHub Actions вернёт ошибку, открой: https://github.com/revuallrabota-coder/my-ai-video-editor/actions/workflows/upload-video-50mb.yml . Код новой цепочки пока не проверен реальным end-to-end тестом.
