▶️ Тест: монтаж без API ID (видео до 20 МБ)

Каждый запуск GitHub Actions можно настроить по-разному: mode, subtitle_style, color, font_profile, caption_position, camera_style, video_speed, video_filter, audio_profile и hook_text. Параметры из записи «Чит-Кода» не закреплены как обязательные. Выбор на экране Mini App пока служит предпросмотром; в обработку передаются именно параметры запуска Actions. После отправки видео бот сначала пришлёт текст распознанной речи: /ok подтвердить, /text ТВОЙ ПОЛНЫЙ ТЕКСТ исправить. Зум теперь привязан к паузам и фразам. Вставки своих фото, эмодзи и звуковые акценты пока не реализованы.

Важно: это первая версия интерфейса, а не готовый видеоредактор. Файлы остаются на устройстве, монтаж и отправка готового ролика в Telegram пока не подключены. Настройки сохраняются отдельным JSON-файлом.
