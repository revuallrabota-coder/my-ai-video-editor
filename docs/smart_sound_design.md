# Автоматическая звуковая режиссура Reels

Обновлено: 22.11.2026. Старый экран содержал 3 независимых настройки «Звуковые акценты на словах», «Звуки субтитров» и «Звуки вставок», а Vintage автоматически принудительно включал печатную машинку. Это было непонятно и могло приводить к избыточному звуковому оформлению.

Теперь **один главный выбор** `soundDesign` в `index.html`. Он разворачивается в три уже существующих валидируемых сервером канала `sound_effects`, `subtitle_sfx` и `insert_sound`:

| Режим UI | Звук на ключевых словах | Звук титров | Звук смысловых анимаций |
| --- | --- | --- | --- |
| Автоматически (по умолчанию) | off | off | on |
| Очень деликатно | off | soft (только на выбранных фразах) | on |
| Выразительнее | soft | tick | on |
| Без добавленных звуков | off | off | off |
| Настроить отдельно | значение из расширенной панели | значение из панели | переключатель |

**Не смешивать «Автоматически» и «Без звука»:** автоматические SFX слышны при смысловых анимациях, а когда подходящего события нет, остаётся чистая исходная дорожка речи. Не создавать искусственный фон или музыку без явного запроса. Переключение визуальной эстетики не переписывает пользовательские звуковые настройки.

## Семантический звук самой вставки

`guide18_fx.sound_family` выбирает звуковую категорию по событию `GuideCue.effect`, **не** по номеру вставки или случайному чередованию. `sound_track` в этой версии создаёт собственные тихие синтезированные акценты:

| Реальный визуальный эффект | Соответствующий звук |
| --- | --- |
| Карусель нескольких кадров | приглушённое пролистывание / шорох |
| Фото/пример | краткий мягкий затвор |
| Сравнение | два акцента «А / Б» |
| Главное слово | один деликатный удар |
| Объяснение | мягкий стеклянный оттенок |
| Этапы | 3 последовательных щелчка |
| Результат/прогресс | плавное повышение тона |
| Важное уведомление | 2 приглушённых сигнала |

Тембр зависит от `insert_style`: Old Money ниже и теплее, Burgundy темнее, Pink Tender очень тихий и воздушный, Vintage приглушённый. Реалистичные лицензированные стоковые WAV/MP4 остаются приватными ассетами на сервере и должны подключаться отдельно; текущая версия не претендует на звучание реальных записанных объектов.

## Безопасность и звук
- Не менять исходную голосовую дорожку и не заглушать говорящего.
- Не навязывать звуковой эффект субтитрам на каждом слове.
- Дублирующие пользовательские настройки доступны только через «Настроить звуки отдельно».
- Если выключено всё, звук голосовой дорожки исходного видео сохраняется (без дополнительных SFX).
- Никаких музыкальных произведений или лицензированных звуков в публичный репозиторий.
- Связанные проверки: `test_smart_sound_design.py`, `.github/workflows/smart-montage-checks.yml`.

## Публикация
Это изменение не меняет API: текущий Cloudflare Worker **contract 6** понимает все три поля. Если сервер уже на версии 6, дополнительная публикация Worker не требуется. Если старая версия, обновить `cloudflare_launcher_ipad.txt` до 6. Новое Mini App появится после публикации GitHub Pages. Работоспособность финального MP4/Telegram нужно подтвердить сквозным тестом, не путать коммит с успешным рендером.
