# Умный смысловой монтаж — вместо 18 разрозненных эффектов

С 22 ноября 2026 года Mini App показывает простой выбор:
1. **✨ Умный монтаж** (по умолчанию): движок подбирает несколько нужных приёмов по фактически произнесённым словам.
2. **🎛 Мои любимые приёмы**: отметить несколько понятных вариантов. Движок использует только их, но исключительно когда они относятся к смыслу речи.
3. **Без дополнительных приёмов**: без сцен из технического гайда; субтитры и отдельная выбранная эстетика остаются.

Модули: `index.html`, `guide18_fx.py`, `reels_effects.py`, `cloudflare_launcher.js` (`cloudflare_launcher_ipad.txt` — точная копия), `process_uploaded_video.py`. Старые 18 техник НЕ удалены из `guide18_fx.py`. В автоматическом режиме восемь наиболее безопасных смысловых семейств. Остальные старые техники остаются для старых заданий; их не запускаем вслепую и без подтверждения соответствующего контекста.

## Маппинг из фактических фраз

| Сигнал в транскрипции | Приём | Что увидит человек |
|---|---|---|
| много / несколько / варианты / список | `pov_carousel_spin` | 3 небольших кадра в карусели, из собственных видео или разрешённых фотографий |
| главное / важно / запомни / ошибка | `match_cut` | выделенное настоящее произнесённое слово |
| сравним / разница / «до…после» | `split_reel` | два небольших кадра рядом |
| объясню / почему / причина | `glass_explainer_reel` | полупрозрачная компактная карточка |
| шаг / этап / «сначала…затем» | `apple_ui_toggles` | последовательная графика |
| покажу / пример / фото | `image_cluster_reel` | фото или кадры из собственного видео |
| результат / прогресс / проценты / «50%» | `liquid_glass_graph` | оживлённый графический акцент без выдуманных чисел |
| внимание / секрет / совет | `notification_stack` | компактная карточка-уведомление |

**Составные фразы** важнее одиночного слова. «Покажу много вариантов» => карусель, не отдельная случайная фотография. «До пяти секунд» не является сравнением, в отличие от «до и после».

## Ограничения автоматического монтажа

- Сохранять первые 4 с только с говорящим человеком и обычными субтитрами.
- Использовать только реальные слова из транскрипции. Если подходящей фразы нет, дополнительный эффект отсутствует. Никаких эффектов «ради количества».
- Подбирать одну главную анимацию на смысловую фразу, сопоставлять соседние триггеры, выдерживать интервалы: subtle ≈10.5 c, balanced ≈7.2 c, dynamic ≈5.1 c (фактический интервал зависит от речи).
- Эффект `compact=True` ограничен по габаритам; он проверяет маску силуэта и область субтитров. Если безопасного места нет, эффект пропускается, исходное видео не маскируется ложной анимацией.
- Анимированные фото берутся только из загруженных фото пользователя или из собственных кадров. Не скачивать изображения Pinterest и не представлять чужие рекламные изображения за контент пользователя.
- Если пользователь отметил несколько любимых эффектов, **ни один не вставляется принудительно**. Сохраняется право на чистый видеомонтаж.
- Соответствующие Old Money, Burgundy, Pink Tender, Vintage источники и звуки всё ещё принадлежат разным эстетикам. Смысловой планировщик определяет тип анимации; палитра, движение, аудиозвук и стикеры применяются из выбранной эстетики. При коллизии занимать один интервал только одним эффектом вместо отмены оформления на весь ролик.
- Изменение цвета/шрифта не отменяет выбранную эстетику.

## Перед публикацией на iPad

Новая версия формата Worker — **6**. Скопировать `cloudflare_launcher_ipad.txt` в Cloudflare Worker и нажать Deploy. Проверить `/health`: `style_contract_version:6`. Мини-приложение прекратит загрузку при версии ниже 6; это намеренная защита от старых схем эффекта.

Автоматические тесты: `test_smart_semantic_montage.py`; workflow `.github/workflows/smart-montage-checks.yml`. Статус рабочего сквозного экспорта в Telegram необходимо отдельно проверить: сохранение в GitHub не разворачивает Cloudflare Worker и не гарантирует доступность MediaPipe на рендере.

*Техническая честность:* текущий классификатор контекста основан на реальных словах, небольших соседних фразах и правилах приоритета, не на полноценном понимании произвольного сценария нейросетью. Он может пропустить метафоры/сложные контексты; в таком случае намеренно оставляет чистый ролик.
