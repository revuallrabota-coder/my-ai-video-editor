# Загрузка видео до 300 МБ с iPad в Telegram Mini App

**В GitHub код обновлён. Для реального лимита 300 МБ надо отдельно опубликовать новую версию существующего Cloudflare Worker.** Это не происходит автоматически после коммита GitHub. Проверка кода GitHub Actions не доказывает, что твой Cloudflare уже обновлён.

## Что теперь поддерживается

- Максимум исходного файла: **300 000 000 байт** (300 МБ, десятичные).
- Файл передаётся в Cloudflare Workers KV по **4 000 000 байт** на часть: максимум **75 частей**. В памяти iPad и Cloudflare Worker не собирается весь 300-МБ файл.
- Если связь прервалась, повторно выбери **тот же файл, настройки и адрес Worker** и нажми «Смонтировать Reels»: приложение получает список сохранённых частей и продолжает загрузку. Запись о прерванной загрузке хранится на этом устройстве до 2,5 часов, сервер хранит части три часа.
- GitHub Actions принимает эти части по защищённому каналу, собирает MP4 на диске и монтирует ролик. Длительность по-прежнему до 125 секунд.
- Готовый файл размером до 48 МБ бот отправляет документом в Telegram. Больший выходной MP4 (до 250 МБ) временно доступен в Mini App через кнопку скачивания. Больший результат пока не поддерживается без отдельного хранилища.

## Публикация обновления на iPad

1. В Safari открой [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Перейди в **Workers & Pages** и выбери существующий Worker, который используется для нашего бота (в прежней инструкции он назывался **black-violet-9e64**). Создавать новый Worker не требуется.
3. Проверь **Settings → Bindings**: у Worker должен быть KV namespace, привязанный **точно под именем UPLOADS**. Если привязки нет, создай namespace в **Storage & databases → KV**, затем добавь Binding → KV namespace → UPLOADS.
4. Открой файл [cloudflare_launcher.js](https://github.com/revuallrabota-coder/my-ai-video-editor/blob/main/cloudflare_launcher.js) в GitHub. Нажми **Raw**, скопируй его содержимое.
5. Открой в Cloudflare **Edit code**, замени старый код Worker целиком на этот JS и нажми **Deploy**. Секреты `TELEGRAM_BOT_TOKEN`, `OWNER_TELEGRAM_ID` и `GITHUB_PAT` менять не нужно, если они уже настроены.
6. Открой `https://АДРЕС-ТВОЕГО-WORKER.workers.dev/health`. Должно появиться `"max_upload_mb":300` и `"uploads_300mb_configured":true`. Если `false`, не настроен Binding UPLOADS. Если 300 отсутствует, загружена старая версия JS.
7. Открой мини-приложение из меню Telegram-бота. Выбери вертикальное MP4/MOV видео до **300 МБ**, длительность до **2 минут**. На последнем экране вставь адрес Worker **без /health** и нажми **«Смонтировать Reels»**.
8. Не закрывай приложение до завершения передачи, следи за процентом. Если соединение оборвалось, снова открой приложение, выбери тот же исходник и повтори запуск для возобновления.
9. Дождись черновика текста в Telegram, подтверди командой `/ok` или исправь командой `/fix`. После монтажа готовый Reels появится в Telegram или в скачивании Mini App.

**Не отправляй секреты и пароли в чат или публичные файлы.**

## Ограничения, которые действительно остаются

- Обычная передача видео непосредственно сообщением Telegram-боту пока ограничена **20 МБ на скачивание** из стандартного Bot API. 300 МБ принимаются **через Mini App**, минуя этот маршрут.
- Бесплатный Cloudflare Workers KV по состоянию на ноябрь 2026 года ограничен **1 ГБ хранения**, **1 000 записей в день** и **25 МиБ на одно значение**. Один исходник 300 МБ занимает 75 разных ключей; вместе с готовым MP4 и служебными записями дневная квота расходуется быстрее. Не запускай несколько крупных роликов одновременно.
- Сохранять результат до 250 МБ в KV и держать исходник в течение обработки возможно только пока хватает места. По истечении трёх часов файлы удаляются; сохраняй готовый ролик своевременно.
- GitHub Actions может не справиться с очень тяжёлой кодировкой или долгим видео. **Успешные автоматические тесты не заменяют первый реальный тест 200–300 МБ.**
- URL нашего старого workflow `upload-video-50mb.yml` сохранён специально, чтобы не сломать связь Worker ↔ GitHub; внутри он уже называется «до 300 МБ».
- Путь через отдельный сервер Render также получил лимит 300 МБ в коде, но бесплатный сервер с ограниченной памятью и диском может не справиться с файлом такого размера. Основной путь для iPad: **Mini App → Cloudflare → GitHub Actions**.
