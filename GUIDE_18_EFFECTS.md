# Реализация PDF «12 эффектов и 6 стилей для твоих рилсов» (13 страниц)

Оригинальный гайд от **neurofam.** содержит **18 текстовых промптов** для Claude Code и HyperFrames, а не исходники MOV, WAV, Lottie, лицензированные ассеты или библиотеку музыки. Наш iPad + Cloudflare + GitHub Actions использует **собственную процедурную адаптацию на Pillow/FFmpeg**, без установки HyperFrames/Claude Code на iPad. Это не идентичные анимации автора, а реализованные сходные приёмы, с неизменным звуком голоса клиента.

## Монтаж без конфликтующих анимаций

В приложении есть селектор **«12 эффектов + 6 стилей из PDF»**. Выбирай конкретный приём или **«Автомонтаж по смыслу речи»**. Планировщик `guide18_fx.plan()` выдаёт события максимум по 3 секунды; минимальное расстояние между началами 5/7/10 секунд, поэтому после каждого события остаётся пауза. При активных PDF-сценах стандартные **крупные** студийные фотокарточки, ретро-стикеры и motion-коллажи отключаются; не накладываются два основных эффекта в один момент. Обычные синхронные субтитры и неяркие звуки остаются.

Автомонтаж выбирает тему только из подтверждённых слов речи. Конкретный эффект не должен появляться, если фраза отсутствует. Если пользователь выбрал вручную режим, он может появиться повторно на других 3-секундных фрагментах. Выбор палитры, шрифта и фильтра остаётся отдельным.

## Медиа и аудио

Фотографии из приватных ZIP: `.jpg`, `.jpeg`, `.png`, `.webp`, до 24 файлов, проверяются Pillow и не публикуются в GitHub. Если их нет, коллажи делаются из настоящих кадров исходного видео. Допускаются MOV и WAV/MP3/M4A/OGG внутри приватных архивов по прежним правилам.

В PDF **нет скачиваемых SFX** и нет конкретного списка музыкальных лицензий. Поэтому исходные чужие звуки не скопированы; создана собственная вариативная дорожка из трёх безопасных типов: воздушный Whoosh, короткие механические щелчки, Pop. Два одинаковых типа подряд не выбираются. Копирование чужих Instagram/Pinterest-роликов без разрешения не выполняется.

## Пределы воспроизведения и проверка

- `guide18_fx.py` выдаёт динамические RGBA-кадры 360×640/15fps, которые затем масштабируются FFmpeg до **реального вертикального кадра** (в нормальном экспорте 1080×1920/30fps); сохраняется оригинальная звуковая дорожка.
- Вырезание человека требует `mediapipe` и сетевой загрузки модели; если модель недоступна, эффект прерывается понятной ошибкой, **без ложного заявления, что вырезание сделано**.
- Некоторые режиссёрские эффекты являются упрощёнными адаптациями: особенно 3D-телефон (не настоящий полноценный рендер 3D), пружинные движения и движение 3D-карусели. Не обещать побуквенного совпадения с видео из гайда.
- В CI добавлены регрессионные тесты: 18 различных динамических кадров, точное перечисление эффектов, анти-наложение, вариативная дорожка, фактический исходный видеофрагмент.
- **Сквозной пользовательский Telegram-экспорт ещё не подтверждён.** Проверять через оригинальное видео 10–15 секунд, один эффект и `/ok`; только после успешной проверки включать авто-монтаж на длинном видео.

## iPad / Cloudflare

Поскольку в серверные настройки добавлен параметр `guide_effect`, обновлены `cloudflare_launcher.js` и `cloudflare_launcher_ipad.txt`. Следующий совместимый контракт: **`style_contract_version:4`**. GitHub Pages обновляет интерфейс автоматически, но опубликованный Worker требуется обновить вручную один раз через Edit code → Deploy. Переписывать токены и `UPLOADS` не нужно. Проверить на `/health`, затем открыть мини-приложение Telegram заново.

## Гайд, стр. 13

Каждый приём сохранён как переиспользуемый именованный рецепт, чтобы можно было подставить другой исходник и новый текст. Порядок нескольких сцен в режиме Auto формируется по речи; исходный MP4 не переписывается, готовый результат создаётся отдельно. Сначала тестируй один эффект и корректность лица, субтитров, маски и последнего кадра, затем целый монтаж.
